css-neon

纯原生 ES Module 霓虹灯特效 Web Component，基于 Shadow DOM v1 和 Custom Elements v1。支持文字和 SVG 两种内容，通过 SVG filter + CSS 动画实现霓虹发光效果。

快速开始 从源码构建 Light DOM 内容 外部 SVG 文件 字体加载 全局属性 文字专属属性 SVG 专属属性 配置级联规则 动画预设 SVG 断管 & 流光 Per-Path / Per-Char 配置 排版属性 CSS 自定义属性 JavaScript API 在 React 中使用 浏览器兼容性

快速开始

<script type="module" src="css-neon.js"></script>

<neon-light color="#ff69b4" glow="12" font-size="64"
            style="width:600px;height:120px">
  霓虹灯效果
</neon-light>
注意：<neon-light> 必须设置明确的 width 和 height（通过 style 或 CSS）。

从源码构建

css-neon.js 由 build/bundle.js 从 src/ 目录下的 6 个源模块自动生成。

构建命令

node build/bundle.js

构建流程

  1. 读取 src/index.js（入口模块）
  2. 递归解析 import { ... } from './...' 语句，构建完整依赖图
  3. 按依赖顺序合并模块（被依赖的在前）：
utils.js → config.js → animations.js → renderer.js → neon-light.js → index.js
  1. 剥离所有内部 import / export 声明
  2. 保留入口模块的公开 API：export { NeonLight, define }
  3. 写入 css-neon.js（约 700 行 / 22 KB）

src/ 模块说明

模块职责
src/utils.jsSVG 命名空间、元素创建、类型转换
src/config.js默认值、属性观察列表、配置级联解析
src/animations.jsflicker / breath / glitch / broken / flow 五种 CSS 动画

Light DOM 内容

<neon-light> 内部可以放置两种内容，按从左到右的流式布局居中排列：

内容类型说明
纯文本渲染为霓虹发光文字
<svg> 元素提取内部形状（path / circle / rect 等）渲染为霓虹描边
<!-- 文字 + SVG 图标 -->
<neon-light color="#ff69b4" glow="10" font-size="48"
            style="width:700px;height:120px">
  NEON
  <svg viewBox="0 0 24 24" width="48" height="48">
    <circle cx="12" cy="12" r="10"/>
  </svg>
</neon-light>

外部 SVG 文件（src 属性）

通过 src 属性直接引用外部 SVG 文件，无需 JavaScript。文件加载后自动 append 到 Light DOM，触发重渲染。

<neon-light color="#00ccff" glow="12"
            svg-animate="flow" svg-stroke-width="4"
            src="css-neon.svg" svg-width="300" svg-height="100"
            style="width:300px;height:100px">
</neon-light>
属性类型默认值说明
srcURL—外部 SVG 文件路径
svg-widthnumber文件原始宽度覆盖外部 SVG 的显示宽度
svg-heightnumber文件原始高度覆盖外部 SVG 的显示高度

字体加载与文字路径化（font-src 属性） new

通过 font-src 加载 TTF/OTF/WOFF 字体文件（使用 opentype.js），将文字转为精确的 SVG glyph 路径渲染。

路径化后的文字具备以下能力：

  • SVG 专属动画：broken（断管）和 flow（流光）直接作用于文字
  • Per-char 配置：通过 path-config 给每个字符单独设置颜色或破管状态
  • 精确字形：使用字体原始 glyph 轮廓，不依赖浏览器字体引擎
<neon-light color="#ffaa00" glow="5"
            svg-animate="broken" broken-ratio="0.3" svg-stroke-width="3"
            font-src="fonts/Inter-Regular.ttf"
            font-size="72" style="width:700px;height:180px">
  CSS-NEON
</neon-light>
属性类型默认值说明
font-srcURL—字体文件路径（TTF/OTF/WOFF）
字体格式：font-src 不支持 WOFF2 格式。如需使用 WOFF2 字体，请先转换为 TTF 或 WOFF。字体通过 opentype.js（动态 import esm.sh）解析，按类级别缓存——多个 <neon-light> 实例共享同一字体文件只需加载一次。加载失败时自动回退到标准文字渲染。

同时作用于文字和 SVG（可被 text-* / svg-* 前缀属性覆盖）。

配置级联规则

text-*  >  svg-*  >  全局属性  >  默认值

每种属性只影响对应的内容类型，互不干扰：

  • 文字 → text-* → 全局属性 → 默认值
  • SVG → svg-* → 全局属性 → 默认值

动画预设

通用动画（文字和 SVG 均可用）

值效果时长 (speed=1)

Per-Path / Per-Char 配置 new

可以对 SVG 中特定的 <path> 或文字路径化后的每个字符单独设置颜色和破管状态。

语法

path-config="<id>: <key>:<value>, <key>:<value>; ..."
  • 每条规则用 ; 分隔，每条规则内属性用 , 分隔，键值对用 : 分隔
  • SVG 路径：<id> 匹配元素 id 或 p-id 属性
  • 文字字符（需 font-src）：<id> 为字符索引（0-based），如 0 代表第一个字符

支持的属性

属性值说明
colorCSS 颜色值覆盖该 path / 字符的描边颜色
brokentrue / false / 1 / 0强制该 path / 字符为破管或正常状态

破管分配逻辑

  1. broken:true 的 path / 字符始终为破管
  2. broken:false 的 path / 字符始终为正常
  3. 未指定的 path / 字符由全局 broken-ratio 决定，通过内容 hash 确定性选取
<!-- SVG per-path：精确控制每个 path 的颜色和破管状态 -->
<neon-light color="#ffaa00" glow="14"
            svg-animate="broken" broken-ratio="0.5"
            svg-stroke-width="5"
            path-config="5739: color:#ff4444, broken:true; 5741: color:#4488ff, broken:false"
            src="beer.svg" svg-width="72" svg-height="72"
            style="width:700px;height:180px">
</neon-light>

<!-- 文字 per-char（需 font-src）：控制每个字符的颜色和破管状态 -->
<neon-light color="#ffaa00" glow="5"
            svg-animate="broken" broken-ratio="0.5" svg-stroke-width="3"
            font-src="fonts/Inter-Regular.ttf"
            path-config="0: color:#ff4444, broken:true; 3: color:#44ff88; 5: color:#4488ff, broken:true"
            font-size="72" style="width:700px;height:180px">
  CSS-NEON
</neon-light>

JavaScript API

import { NeonLight, define } from './css-neon.js';

// 自动注册（默认标签名 <neon-light>）
define();

// 自定义标签名
define('my-neon', NeonLight);

NeonLight 继承自 HTMLElement，所有标准 DOM API 均可使用：

const el = document.querySelector('neon-light');
el.setAttribute('color', '#ff0000');   // 自动触发重渲染
el.setAttribute('animate', 'flicker');

属性变化会自动触发 attributeChangedCallback 重渲染。修改 Light DOM 内容（添加/移除文字或 SVG）也会通过 MutationObserver 触发重渲染。

在 React 中使用

css-neon 是纯 Web Component，不依赖任何框架。在 React 项目中可以直接引入使用。

引入方式

把 css-neon.js 放入 src/ 目录，在入口文件或组件中 import（推荐）：

// src/index.js 或 src/App.jsx
import './css-neon.js';  // 副效应导入，自动注册 <neon-light> 标签

JSX 中使用

引入后在 JSX 中直接当 HTML 标签使用即可：

function App() {
  return (
    <neon-light color="#ff69b4" glow={12} font-size={64}
                style={{ width: 600, height: 120 }}>
      CSS-NEON
    </neon-light>
  );
}

style 属性的写法 重要

React 的 style 属性只接受对象，不接受字符串。这是 React 的设计决定，对自定义元素同样适用。

✅ React / JSX 正确写法❌ 错误写法（会报错）
style={{ width: 600, height: 120 }} style="width:600px;height:120px"

如果写成字符串，React 会抛出以下错误：

The `style` prop expects a mapping from style properties to values,
not a string. For example, style={{marginRight: spacing + 'em'}}
when using JSX.
提示：数字类型的 style 值默认以 px 为单位，所以 { width: 600 } 等价于 CSS 的 width: 600px。如需其他单位，请使用字符串 { width: '100%' }。

TypeScript 类型声明

如果项目使用 TypeScript，在 .d.ts 文件中添加以下声明以消除类型错误：

declare namespace JSX {
  interface IntrinsicElements {
    'neon-light': React.DetailedHTMLProps<
      React.HTMLAttributes<HTMLElement>,
      HTMLElement
    >;
  }
}

动态修改属性

React 的虚拟 DOM 不会自动将 prop 同步为 Web Component 的 attribute。如果需要在运行时动态修改属性，建议通过 ref 操作：

import { useRef, useEffect } from 'react';

function App() {
  const neonRef = useRef(null);

  useEffect(() => {
    neonRef.current?.setAttribute('color', '#00ccff');
  }, []);

  return (
    <neon-light ref={neonRef} glow={10} font-size={48}
                style={{ width: 600, height: 120 }}>
      DYNAMIC NEON
    </neon-light>
  );
}
